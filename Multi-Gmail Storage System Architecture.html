សមាសភាគប្រព័ន្ធ (System Components Breakdown)

Frontend (Unified User Dashboard)

ផ្ទាំង UI កណ្តាលមួយសម្រាប់គ្រប់គ្រងមើល file ទាំងអស់។ អ្នកប្រើប្រាស់មិនបាច់ Login ចេញចូល Gmail ផ្សេងគ្នានោះទេ គឺប្រើប្រាស់ចំណុចប្រទាក់តែមួយ។

Backend API & Smart Storage Router

ខួរក្បាលកណ្តាលសរសេរដោយ Node.js/Python ធ្វើការពិនិត្យ Quota របស់ Google Drive API នីមួយៗ និងមាន Refresh Token សម្រាប់ Auth ដោយស្វ័យប្រវត្តិ។

Storage Layer (Google Drive / Gmail API)

គណនី Gmail នីមួយៗដែលទទួលបាន 15GB Free។ នៅពេល Account ទី១ ពេញ Smart Router នឹងផ្លាស់ប្តូរទិសដៅ upload ទៅកាន់ Account ទី២ ភ្លាមៗ។

អត្ថប្រយោជន៍ និងលំហូរការងារ (Workflow Benefits)

  • ចំណេញថវិកា (Cost-Effective): ប្រើប្រាស់ទំហំ 15GB ឥតគិតថ្លៃពី Google នៃ Gmail ជាច្រើន បង្កើតបានជា Cloud Storage ធំមួយ។
  • ដំណើរការស្វ័យប្រវត្តិ (Automated Overflow): អ្នកប្រើប្រាស់គ្រាន់តែចុច Upload ឯកសារ នោះប្រព័ន្ធនឹងរៀបចំទិសដៅទុកដាក់ដោយខ្លួនឯង។
  • ការចាក់ផ្សាយរលូន (Seamless Streaming): Backend អាចបម្រើជា Media Gateway ដើម្បីទាញយកវីដេអូពី Gmail ផ្សេងៗមក Stream លើ App តែមួយ។
  • ងាយស្រួលពង្រីក (Scalable): អាចបន្ថែម Gmail OAuth លេខ 5, 10, 20... បន្តទៀតបានគ្រប់ពេលវេលា។
